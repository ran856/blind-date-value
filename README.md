# 相亲市场价值测评

一个**单文件网页**趣味测试：12 道题，测出你在相亲市场的估值段位、优势项与短板项，并可一键导出 **1080×1440（3:4）分享图与封面图**，适合发小红书。

## 在线体验

👉 https://ran856.github.io/blind-date-value/

## 特点

- **单文件、零依赖**：`index.html` 一个文件搞定，离线可用，手机优先，明暗自适应
- **12 题 4 维度**：🏠 硬件（房车/收入/外形）· 💬 软件（情绪价值/生活能力/沟通）· 🌐 供需（城市/圈子/家庭/心态）· 🛡️ 风控（财务/前任/独立性），权重 30/30/20/20
- **8 级段位**：SSS 钻石级稀缺资产 → SS 硬通货 → S 优质流通品 → A 稳健白马 → B 潜力股 → C 谨慎持有 → D 重组概念股 → E 暂缓挂牌
- **结果页**：分数环 + 四维条 + 一句话锐评 + 溢价项 + 短板项 + 挂牌建议
- **可导出的图**：结果分享图、封面图（都是 1080×1440），手机端长按即可保存
- **一键复制文案**：自动带话题标签
- **彩蛋**：🤖「AI 在相亲市场值多少」——51 分 · C 级谨慎持有
- **纯娱乐**：页脚与结果页均声明「人不是商品，分数也不能定义你」

## 本地使用

下载 `index.html` 双击打开即可；或起个静态服务：

```bash
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

## 自检

页面逻辑（答题流程 / 计分分档 / 分享图 canvas 绘制 / 文案复制）有一套无头断言测试，
仓库里未附带测试脚本；如需扩展题目，改 `index.html` 里的 `QS` 数组即可（每题 `{d, q, o:[[选项文案, 分值], ...]}`）。
